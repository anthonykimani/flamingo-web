# TypeScript Interfaces

## Overview

All TypeScript interfaces are located in `/interfaces` and provide type safety across the application.

## Quiz Interfaces

**File:** [interfaces/IQuiz.ts](../../interfaces/IQuiz.ts)

### IQuiz
Main quiz structure containing all quiz data.

```typescript
export interface IQuiz {
  id?: string;
  title: string;
  questions: IQuestion[];
  isPublished?: boolean;
  createdAt?: string;
  updatedAt?: string;
}
```

**Properties:**
- `id`: Unique quiz identifier (optional, generated by backend)
- `title`: Quiz display name
- `questions`: Array of quiz questions
- `isPublished`: Publication status (optional, defaults to false)
- `createdAt`: ISO timestamp of creation (optional)
- `updatedAt`: ISO timestamp of last update (optional)

**Usage Example:**
```typescript
const quiz: IQuiz = {
  title: "World Geography",
  questions: [
    // ... questions array
  ]
};
```

### IQuestion
Individual question structure within a quiz.

```typescript
export interface IQuestion {
  id?: string;
  questionNumber: number;
  question: string;
  answers: IAnswer[];
  createdAt?: string;
}
```

**Properties:**
- `id`: Unique question identifier (optional)
- `questionNumber`: Sequential question number (1-indexed)
- `question`: Question text displayed to players
- `answers`: Array of possible answers (typically 4 options)
- `createdAt`: ISO timestamp (optional)

**Usage Example:**
```typescript
const question: IQuestion = {
  questionNumber: 1,
  question: "What is the capital of France?",
  answers: [
    { answer: "Paris", correctAnswer: true },
    { answer: "London", correctAnswer: false },
    { answer: "Berlin", correctAnswer: false },
    { answer: "Madrid", correctAnswer: false }
  ]
};
```

**Rules:**
- `questionNumber` should be sequential starting from 1
- Must have at least 2 answers
- Exactly ONE answer must have `correctAnswer: true`
- Typically 4 answers for consistency

### IAnswer
Answer option for a question.

```typescript
export interface IAnswer {
  id?: string;
  answer: string;
  correctAnswer: boolean;
  deleted?: boolean;
}
```

**Properties:**
- `id`: Unique answer identifier (optional)
- `answer`: Answer text displayed to players
- `correctAnswer`: Whether this is the correct answer
- `deleted`: Soft delete flag (optional, used in editing)

**Usage Example:**
```typescript
const answer: IAnswer = {
  answer: "Paris",
  correctAnswer: true
};
```

**Validation Rules:**
- Only ONE answer per question can have `correctAnswer: true`
- Answer text should be concise (recommend < 50 characters)
- Empty answer strings not allowed

### IPlayer
Player statistics and state during gameplay.

```typescript
export interface IPlayer {
  id: string;
  playerName: string;
  totalScore: number;
  correctAnswers: number;
  wrongAnswers: number;
  currentStreak: number;
  bestStreak: number;
}
```

**Properties:**
- `id`: Unique player identifier
- `playerName`: Display name chosen by player
- `totalScore`: Cumulative points earned
- `correctAnswers`: Count of correct answers
- `wrongAnswers`: Count of incorrect answers
- `currentStreak`: Current consecutive correct answers
- `bestStreak`: Highest streak achieved in this game

**Usage Example:**
```typescript
const player: IPlayer = {
  id: "player_123",
  playerName: "Alice",
  totalScore: 5000,
  correctAnswers: 5,
  wrongAnswers: 1,
  currentStreak: 3,
  bestStreak: 4
};
```

**Calculated Values:**
```typescript
// Total questions answered
const totalAnswers = player.correctAnswers + player.wrongAnswers;

// Accuracy percentage
const accuracy = (player.correctAnswers / totalAnswers) * 100;

// Average points per question
const avgPoints = player.totalScore / totalAnswers;
```

### IGameSession
Game session data structure (inferred from usage).

```typescript
interface IGameSession {
  id: string;
  gamePin: string;
  quizId: string;
  status: GameState;
  players: IPlayer[];
  currentQuestionIndex: number;
  hostWalletAddress?: string;
  prizePool?: number;
  createdAt: string;
  startedAt?: string;
  completedAt?: string;
}
```

**Properties:**
- `id`: Unique session identifier
- `gamePin`: 6-digit PIN for players to join
- `quizId`: Reference to quiz being played
- `status`: Current game state (GameState enum)
- `players`: Array of joined players
- `currentQuestionIndex`: Current question (0-indexed)
- `hostWalletAddress`: Host's wallet (for escrow)
- `prizePool`: Total prize amount in wei (optional)
- `createdAt`: Session creation timestamp
- `startedAt`: Game start timestamp (optional)
- `completedAt`: Game completion timestamp (optional)

**Usage Example:**
```typescript
const session: IGameSession = {
  id: "session_abc123",
  gamePin: "123456",
  quizId: "quiz_xyz789",
  status: GameState.WAITING,
  players: [],
  currentQuestionIndex: 0,
  createdAt: new Date().toISOString()
};
```

## Response Interfaces

**File:** [interfaces/IResponse.ts](../../interfaces/IResponse.ts)

### IResponse
Standardized API response wrapper.

```typescript
export interface IResponse {
  message: string;
  payload: any;
  status: number;
  ok: boolean;
  statusText: string;
  json: any;
}
```

**Properties:**
- `message`: Human-readable response message
- `payload`: Response data (varies by endpoint)
- `status`: HTTP status code (200, 400, 404, 500, etc.)
- `ok`: Boolean indicating success
- `statusText`: HTTP status text
- `json`: JSON response data

**Success Response Example:**
```typescript
const response: IResponse = {
  message: "Quiz created successfully",
  payload: {
    id: "quiz_123",
    title: "My Quiz",
    // ... quiz data
  },
  status: 200,
  ok: true,
  statusText: "OK",
  json: { /* ... */ }
};
```

**Error Response Example:**
```typescript
const response: IResponse = {
  message: "Quiz not found",
  payload: null,
  status: 404,
  ok: false,
  statusText: "Not Found",
  json: { error: "Quiz not found" }
};
```

**Usage Pattern:**
```typescript
async function fetchQuiz(id: string): Promise<IResponse> {
  try {
    const response = await getQuizById(id);

    if (response.ok) {
      return response;
    } else {
      throw new Error(response.message);
    }
  } catch (error) {
    console.error('Error:', error);
    throw error;
  }
}
```

## Type Guards

### Utility Type Guards
```typescript
// Check if quiz is valid
function isValidQuiz(quiz: any): quiz is IQuiz {
  return (
    typeof quiz === 'object' &&
    typeof quiz.title === 'string' &&
    Array.isArray(quiz.questions) &&
    quiz.questions.length > 0
  );
}

// Check if question has correct answer
function hasCorrectAnswer(question: IQuestion): boolean {
  return question.answers.some(a => a.correctAnswer === true);
}

// Validate player data
function isValidPlayer(player: any): player is IPlayer {
  return (
    typeof player === 'object' &&
    typeof player.id === 'string' &&
    typeof player.playerName === 'string' &&
    typeof player.totalScore === 'number'
  );
}
```

## Usage Best Practices

### 1. Always Import Interfaces
```typescript
import { IQuiz, IQuestion, IAnswer } from '@/interfaces/IQuiz';
import { IPlayer } from '@/interfaces/IQuiz';
import { IResponse } from '@/interfaces/IResponse';
```

### 2. Use Type Annotations
```typescript
const [quiz, setQuiz] = useState<IQuiz | null>(null);
const [players, setPlayers] = useState<IPlayer[]>([]);
const [questions, setQuestions] = useState<IQuestion[]>([]);
```

### 3. Type Function Parameters
```typescript
function createQuestion(questionData: IQuestion): void {
  // Implementation
}

function submitAnswer(answer: IAnswer): Promise<IResponse> {
  // Implementation
}
```

### 4. Validate Data at Boundaries
```typescript
async function saveQuiz(quizData: IQuiz): Promise<IResponse> {
  // Validate before sending to API
  if (!isValidQuiz(quizData)) {
    throw new Error('Invalid quiz data');
  }

  return await addQuiz(quizData);
}
```

### 5. Use Optional Chaining
```typescript
const quizTitle = quiz?.title ?? 'Untitled Quiz';
const playerName = player?.playerName ?? 'Anonymous';
```

```typescript
const formData: QuizFormData = {
```

```typescript
const stats: PlayerStats = {

  bestStreak: 4
};
```

```typescript
const updates: PartialQuiz = {
```
